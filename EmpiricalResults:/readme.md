*This folder contain Mplus output files of the empirical examples in the article. All analyses were run on data from the Leuven 3-Wave Longitudinal Study (Erbas, et. al., 2018).* 

### Explanation of model names:

While developing the models, we took in-between steps in slowly increasing model complexity, which is not reported in the paper. Hence, model files have, in part, different names than in the paper.

- m0 models contain the variance decomposition
- m1a/m1b contains models 1a or 1b
- m4a1 /m4b2 contains output of model 2a and model 2b as presented in the paper
