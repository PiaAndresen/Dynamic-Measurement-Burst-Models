*This repository contains supplementary materials for Andresen, Schuurman, & Hamaker (in prep.).
Please navigate this repository as follows:*

- *EmpiricalResults*  contains Mplus output files of the variance decomposition and models 1a&b and 2a&b for variables depression, confidence (in article), cheerfulness, stress, and anger (not completely presented in article). These output files can be used to check model convergence and verify results presented in the article. Please note that we are not allowed to share the data, our any output file that contains the data.

- The website linked to this repository includes didatical explanations of the syntax

- *R Code*  contains r code used to pre-process data and run models via MplusAutomation.
